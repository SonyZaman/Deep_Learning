# Machine Learning vs. Deep Learning

This document provides a concise study guide outlining the core differences between traditional Machine Learning (ML) and Deep Learning (DL), serving as a quick recap of their fundamental distinctions.

## What is Deep Learning (DL)?
At its core, Deep Learning is powered by **Neural Networks**. 
While traditional Machine Learning relies on standard algorithms such as **KNN (K-Nearest Neighbors), K-Means Clustering, and RF (Random Forest)**, Deep Learning utilizes multi-layered artificial neural networks to process data and make decisions.

---

## Key Differences: ML vs. DL

The primary distinctions between traditional Machine Learning and Deep Learning can be categorized into the following core areas:

### 1. Architecture
- **Machine Learning:** Utilizes simpler algorithmic architectures (like decision trees, support vector machines, or linear models).
- **Deep Learning:** Built on complex, multi-layered **Neural Network Architectures**. The "depth" refers to the multiple hidden layers present in the network, allowing it to process information in a hierarchical manner.

### 2. Representation of Data
- **Machine Learning:** Heavily depends on manual feature engineering. Human experts must often manually define and extract the right features from the raw data before it can be effectively used by the model.
- **Deep Learning:** Learns the **representation of data** automatically. Deep Learning models can take raw data (like pixels of an image) and automatically discover the features and representations necessary to perform a task.

### 3. Non-Linear Relationships
- **Machine Learning:** While some ML algorithms can handle non-linearity, they often struggle with highly complex, non-linear patterns without extensive feature manipulation.
- **Deep Learning:** Naturally excels at capturing and modeling highly complex, **non-linear** relationships within data. This is achieved through the use of non-linear activation functions distributed across the network's layers.
